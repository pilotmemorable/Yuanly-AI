# Yuanly Digital Asset Acquisition Plan

This document serves as the master "shopping list" for all digital properties required to launch the Yuanly ecosystem.

## 1. Domain Strategy
The goal is to maintain a consistent brand identity across all touchpoints.

| Priority | Domain | Purpose | Status | Note |
| :--- | :--- | :--- | :--- | :--- |
| **Primary** | `yuanly.app` | Main User Hub & App Landing | Target | High priority for mobile-first branding |
| **Secondary** | `yuanly.io` | Tech/SaaS & API Documentation | Target | Standard for tech startups |
| **Corporate** | `yuanly.co` | Business/Corporate presence | Target | Clean and professional |
| **Regional** | `yuanly.cn` | Chinese localized portal | Target | Critical for local SEO in China |

## 2. Email Infrastructure
A structured email system is required to separate user support, corporate partnerships, and system administration.

**Primary Domain:** `@yuanly.app`

| Address | Purpose | Access Level |
| :--- | :--- | :--- |
| `hello@yuanly.app` | General inquiries & Marketing | Public |
| `support@yuanly.app` | Customer service & AI-Agent escalations | Public |
| `partners@yuanly.app` | Merchant onboarding & B2B relations | Corporate |
| `admin@yuanly.app` | System root & Technical management | Restricted |
| `billing@yuanly.app` | Payments & Invoicing | Restricted |

## 3. Social & Platform Handles
To ensure brand consistency, the same handle must be secured across all platforms.

**Preferred Handle:** `@yuanlyapp` (Alternative: `@yuanly_official`)

| Platform | Strategic Purpose | Handle |
| :--- | :--- | :--- |
| **Rednote (Xiaohongshu)** | Visual inspiration, Trends, Gen-Z growth | `@yuanlyapp` |
| **WeChat (Official Account)** | Utility, Service, Payments, Loyalty | `YuanlyOfficial` |
| **Instagram** | Global prestige, Visual storytelling | `@yuanlyapp` |
| **TikTok / Douyin** | Short-form viral content, Experience teasers | `@yuanlyapp` |
| **LinkedIn** | Corporate B2B, Partnerships | `yuanly-ai` |

## 4. Registration Process (Action Plan)
Since these require payment and identity verification (KYC), the following steps must be executed by the account owner:
1. **Domain Registration:** Use a registrar (e.g., Cloudflare or Namecheap) to secure the primary `.app` and `.cn` domains.
2. **Google Workspace / Zoho Mail:** Set up the corporate email environment using the primary domain.
3. **Chinese Account KYC:** Register the WeChat Official Account and Rednote Business account using a verified business license.
