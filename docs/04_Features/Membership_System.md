# Yuanly AI - Membership & User System

## 1. Membership Levels
To incentivize loyalty and create a sense of exclusivity, Yuanly uses a tiered membership system.

| Level | Requirement | Benefits | AI Interaction Tone |
| :--- | :--- | :--- | :--- |
| **Guest** | None | Discovery, basic booking | Professional, Welcoming |
| **Silver** | Account Creation | Saved Wishlist, Member-only discounts (5%) | Friendly, Personalized |
| **Gold** | 3+ Bookings | Priority Support, Early access to new experiences | Proactive, Attentive |
| **VIP/Elite** | Top 5% Spending | Secret Experiences, Dedicated Human Concierge, Zero-fee cancellations | Hyper-personalized, Prestigious |

## 2. Onboarding Flow (Mobile-First)
- **Quick Entry:** One-tap login via WeChat ID or Apple ID.
- **Profile Setup:** Minimalist input. Name, Language preference, Travel style (e.g., "Adventure", "Luxury", "Cultural").
- **Interest Mapping:** A short "Tinder-style" swipe session where users like/dislike various Turkey activities to train the AI recommendation engine.

## 3. Security & 2FA (The Shield)
- **Primary Access:** Biometric (FaceID/TouchID) for app entry.
- **Critical Actions:** (Changing payment methods, Large refunds, Corporate setting changes) $\rightarrow$ Trigger SMS or Email 2FA.
- **Trust Score:** Users who consistently provide high-quality reviews gain a "Trust Score", making their profiles more visible in the community.
